# NEXUS Roleplay Website

Static GitHub Pages website for NEXUS Roleplay.

## Deploy
1. Upload `index.html`, `style.css`, `script.js` to a GitHub repository.
2. GitHub → Settings → Pages → Deploy from branch → `main` / root.
3. Replace placeholder Discord/launcher links in `index.html`.
4. Replace the map placeholder with the real NEXUS map when available.

No build step is required.
